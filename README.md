# Projet immobilier familial

Mini-site de synthèse stratégique pour notre projet d'investissement immobilier familial à 5 associés.

## Objectif

Comparer les structures juridiques et fiscales adaptées à un portefeuille de locations meublées (longue durée, colocation et courte durée/Airbnb), puis enrichir progressivement le site avec les simulations financières du projet.

## Site

Le site est statique et se trouve dans `index.html`, prêt à être publié avec GitHub Pages depuis la branche `main` et le dossier racine `/`.

### Activer GitHub Pages

Dans le dépôt : **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.

Une fois Pages activé, le site sera normalement disponible à l'adresse :

`https://jorgesblondel.github.io/projet-immobilier-familial/`

## Avertissement

Cette synthèse est un document de réflexion. Les décisions juridiques, fiscales et financières devront être validées avec les professionnels compétents avant création de la société ou investissement.
